# YousApp

YousApp is a sensing and memory app for group discussions.

It does not decide outcomes. It captures expressed positions, keeps durable memory, and lets people inspect multiple overviews.

## Principles

- Measure expression, not authority.
- Keep raw signals and summaries traceable.
- Allow multiple overviews, not a single canonical view.
- Keep participation voluntary, with clear exit/fork paths.

## Project Structure

- `CONSTITUTION.md`: system boundaries and non-negotiable rules
- `index.html`: app shell
- `src/main.ts`: simple UI render + startup state
- `src/styles.css`: base styles

## Run

1. `cd yousapp`
2. `npm install`
3. `npm run dev`
